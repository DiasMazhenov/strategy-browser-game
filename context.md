# Контекст проекта — «Империи Рассвета» (Empires Dawn)

Мини-стратегия в реальном времени в духе **Age of Empires**: изометрия, сбор ресурсов,
эпохи, юниты, здания, набеги волн, дипломатия с ИИ-соперником. Один HTML-файл на выходе
(весь JS/CSS вшит Vite-плагином `singlefile`), рядом только папка `voices/` с mp3.

**Язык игры и общения — русский. Арт — пиксель-арт (не реализм).**

---

## Текущая версия

**1.0.001** — источник истины: константа `GAME_VERSION` в `src/App.tsx`.
Правило версий: при каждом обновлении поднимаем ТРЕТЬЮ цифру на 1 —
`1.0.001 → 1.0.002 → 1.0.003 …`. Показывается в главном меню в левом нижнем углу
(мелкий полупрозрачный белый текст). В `package.json` поле `version` остаётся валидным
semver `1.0.0`, а реальная версия игры продублирована в `_gameVersion`.

## Технологический стек и сборка

- **Vite + React + TypeScript + Tailwind**, рендер игры — на `<canvas>` 2D (без движка).
- UI (меню, HUD, док, модалки) — React-компоненты в `src/App.tsx`; игровая логика — классы.
- Сборка: `npm run build` → `dist/index.html` (single-file, ~3.86 МБ, gzip ~2.7 МБ) + `dist/voices/`.
- Проверка типов: `./node_modules/.bin/tsc --noEmit` (после `npm install` — node_modules не персистятся между сессиями).
- Деплой — **любой статический/shared хостинг**: залить содержимое `dist/` в `public_html/` (или аналог).
  Бэкенда/БД/Node на сервере НЕ нужно. Сохранения — в `localStorage`.
  Единственная внешняя зависимость — шрифт Playfair Display с Google Fonts (при офлайне — системный фолбэк).

### Команды
```bash
npm install            # если tsc/vite не найдены
./node_modules/.bin/tsc --noEmit   # проверка типов
npm run build          # прод-сборка в dist/
npx http-server dist -p 8080 -c-1  # локальный предпросмотр
```

## Структура кода

| Файл | Назначение |
|---|---|
| `src/App.tsx` | Весь React-UI: меню, HUD, нижний док (войска/стройка), карточки выделения, пауза, настройки, дерево технологий, экран итогов. Здесь `GAME_VERSION`. |
| `src/game/engine.ts` | Класс `Game` — главный движок: мир, камера, ввод, рендер изо, юниты/здания, ИИ, волны, дипломатия, экономика, сохранения. ~3400 строк. |
| `src/game/config.ts` | `BUILDING_DEFS`, `UNIT_DEFS`, `AGES`, `DIFF`, `TECHS`, `WORLD`, настройки. |
| `src/game/iso.ts` | Изометрия: `toIso/fromIso`, `TILE_STEP=32`, ромб 64×32, тайлы травы/земли. |
| `src/game/pixelart.ts` | Процедурная отрисовка юнитов (`drawPixelUnit`), стройки, кольца выделения, тени. |
| `src/game/sprite-art.ts` | `SPR_ANCHORS` (якоря посадки спрайтов зданий) и `UNIT_ANCHORS` (кадры юнитов). |
| `src/game/audio.ts` | Класс `SoundBank`: синтез SFX (WebAudio) + голоса/боевой звук из mp3. |
| `src/assets/sprites/` | PNG-спрайты зданий и `units/` (юниты + кадры `_w` ходьбы). Прозрачные, h≈150px. |
| `public/voices/` | mp3-фразы юнитов (имена файлов = фразы) и `battle-sword-fight.mp3`. |

### Ключевые константы и ограничения (НЕ ломать — см. CONTRIBUTING.md)
- `TILE_STEP = 32`, изо-ромб клетки 64×32.
- Лимит частиц **650** (пыль из-под ног — отдельный лимит <620).
- Куллинг объектов через `inView()`; тайлы кэшируются (`Map`).
- Спрайты лёгкие: после даунскейла высота ~100–150px; ассеты ужаты.
- **TTS/Web Speech запрещены полностью** — озвучка только готовыми mp3 из `public/voices/`.

## Арт-пайплайн спрайтов

1. Генерация через инструмент изображений (gpt image) на **белом фоне**, пиксель-арт, изо 2:1.
2. Сырой файл → `raw/` (в .gitignore).
3. Пост-обработка скриптом `scripts/proc.cjs` (в .gitignore, нативный node+zlib):
   удаление белого фона flood-fill от краёв → обрезка по альфе → box-downscale до h=150
   → слабая чистка бахромы → энкод PNG.
   ```bash
   node scripts/proc.cjs raw/вход.png src/assets/sprites/выход.png 150
   ```
4. Прописать импорт в `engine.ts`, при необходимости якорь в `sprite-art.ts`.
5. Проверка тайлинга стен — оффскрин-композит `scripts/tile-test.cjs` (в .gitignore).

## Стены и ворота (важно)

- Спрайты: `wall.png` (**чистая каменная кладка, БЕЗ дверей/арок**), `gate.png` (ворота с дверью),
  `wall_corner.png` (угловой бастион-столб).
- **Протяжка**: клавиши **B** (стена) / **V** (ворота) → зажать и тянуть; сегменты ставятся
  вдоль доминирующей изо-оси с привязкой к клеткам (`TILE_STEP`).
- Один спрайт на объект; **вторая диагональ рисуется зеркально** по X (`ctx.scale(-1,1)`)
  в `drawWallSprite()` — отдельные `wall_b/gate_b` НЕ нужны (были, удалены как неверно ориентированные).
- **Угол**: `isWallCorner(b)` детектит соседа и вдоль мировой X, и вдоль Y (в пределах клетки) →
  на этой клетке рисуется `wall_corner.png` (зубчатый квадратный столб, масштаб ~0.9, без флипа).
- **Ворота**: свои юниты проходят, враги — стопорятся (коллизии в `updateUnits`).
- Замена участка стены на ворота: выделить стену → кнопка «🚪 Ворота» (`buildGateOnWall()`).
- Снос строения: выделить своё здание → «⛏ Снести» или **Delete/Backspace** (`demolish()`,
  возврат части ресурсов; ГЦ снести нельзя).

## Звук

- Голосовые реплики — mp3 из `public/voices/`, карта фраз в `audio.ts` (`PHRASES`/`CLIP_FILES`).
  Нет файла — фраза молча пропускается. Имена файлов кириллические, берутся через `encodeURIComponent`.
- **Боевой звук** `battle-sword-fight.mp3` (`SoundBank.battleClash()`): играет в рукопашной
  (`strike()`), старт со **случайной секунды** трека (5–40с), короткий фрагмент 2–4с,
  не больше одного одновременно, гейт ~0.9с.

## Бэклог / открытые идеи
- Угол сейчас автоопределяется по соседним сегментам; поворот **в одной протяжке** одной линией (залом) — не сделан.
- Ранее предлагалось: случайные события (чума/урожай/караван), ачивки и баннеры, погодные эффекты.
- Опционально: self-host шрифта для полностью офлайн-версии (сейчас Google Fonts).
